# Factory catalog

## Priority A

### API / Data Oracle Factory
Sources + schema + query contract -> API/dataset/docs/health/provenance.

### App / Micro-SaaS Factory
Verified pain + workflow + distribution -> web app/PWA/service + telemetry/deployment bundle.

### Connector / Integration Factory
API/OpenAPI/docs/SDK -> typed client, CLI, MCP/A2A/webhook integration + tests.

### Agent Service Factory
Capability need + evaluation contract -> worker/tool/skill package + evals + deployment.

### Directory / Vertical Intelligence Factory
Public/licensed sources -> normalized entity index/API/app with freshness/provenance.

## Priority B

### Shop / Marketplace Factory
Two modes:
1. owned storefront
2. marketplace publisher

Adapters: Shopify, Etsy, eBay, Amazon first. Publishing is gated by account/platform eligibility.

### Developer Tool / CLI Factory
Library/CLI/devtool + package metadata, tests and docs.

### Browser Extension Factory
Manifest, minimal permissions, scripts, tests and bundle.

## Priority C

### Dataset / Benchmark Factory
License/provenance/dedupe/leakage/splits/baselines/release.

### Data Pipeline / Automation Factory
Scheduled idempotent ingestion/transformation/reconciliation.

No YouTube factory in core.
