```text

MONETIZATION.md
COMPETITORS.md
SECURITY.md
ROADMAP.md
CHANGELOG.md
```

---

## Documentation Rules

1. **Generated from product state**, not fantasy
2. **Mark unvalidated sections** as `UNVALIDATED`
3. **Include evidence** for all claims
4. **Keep synchronized** with code
5. **Version controlled** in git

---

## Example: MONETIZATION.md

```markdown
# Monetization

## Status: UNVALIDATED

## Proposed Model
- API pricing: $0.001 per call
- Freemium: 1000 calls/month free
- Enterprise: $99/month

## Evidence
- None yet (pre-revenue)

## Validation Plan
- [ ] Get 10 beta users
- [ ] Test pricing with 5 users
- [ ] Measure conversion rate
```
