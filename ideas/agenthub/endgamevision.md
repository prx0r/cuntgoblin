## The Crucial Distinction

> **The Agent Factory can invent an experimental architecture for one solution without pretending that architecture deserves to become a permanent reusable AgentSystem.**

A candidate only gets promoted after repeated benchmark evidence, reproducibility, baseline uplift and an ablation showing that the **architecture itself** contributed—not merely a better underlying model.

---

## Benchmarking is the Real Core

Three benchmark modes:

```text
ARCHITECTURE-CONTROLLED
same models, same tools, same tasks, different architecture

PRODUCTION
architecture + its real HotSwap policies

ABLATION
same architecture, change exactly one mechanism
```
