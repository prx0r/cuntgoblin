# Verified Source Notes — 2026-08-18

Primary/current sources reviewed for this pack.

## AgentBeats
https://docs.agentbeats.dev/
https://docs.agentbeats.dev/tutorial/

Agentified Agent Assessment:
judge/green agents and subject/purple agents, A2A/MCP standardization, reproducible
containerized assessments and GitHub-backed leaderboard workflows.

## A2A
https://a2a-protocol.org/v0.3.0/specification/

Core objects include Message, Task, Part, Artifact and AgentCard-defined HTTP endpoints.

## AgentArch
https://arxiv.org/abs/2509.10769

Benchmarks multiple agentic configurations across orchestration, ReAct/function calling,
memory and thinking tools; reports model-specific architectural preferences.

## MAFBench
https://arxiv.org/abs/2602.03128

Controlled framework-level evaluation of orchestration, memory, planning, specialization
and coordination; framework design can substantially affect latency and coordination.

## OrchBench
https://arxiv.org/abs/2607.25656

Deterministic simulation benchmark for orchestration plans, separating planner quality
from real worker noise/cost; reports strong correlation with real execution in its study.

## OrchestraBench
https://arxiv.org/abs/2608.05263

Failure/recovery/decomposition benchmark using controlled failure injection; introduces
cascade radius and shows blind retry can reproduce latent faults.

## MaAS
https://arxiv.org/abs/2502.04180
https://github.com/bingreeky/MaAS

Agentic supernet and query-dependent architecture sampling with performance/cost feedback.

## AutoMaAS
https://arxiv.org/abs/2510.02669

Self-evolving architecture search with operator lifecycle and cost-aware online feedback.

## Darwin Gödel Machine
https://arxiv.org/abs/2505.22954

Archive/tree based open-ended evolution with empirical benchmark validation and sandboxing.

## ShinkaEvolve
https://github.com/SakanaAI/ShinkaEvolve

Population/island program evolution, parallel evaluation, persistent results, headless
agent mutation support.

## Agentic Computation Graph Survey
https://arxiv.org/abs/2603.22386

Useful representation distinction: reusable template graph, realized runtime graph,
execution trace.

## Hyperagents
https://arxiv.org/abs/2603.19461

Meta-level self-modification beyond task-agent-only evolution; treated as endgame research,
not initial implementation.
