# Architecture Pattern Registry

Extract successful mechanisms separately from whole systems.

Pattern object:
- ID
- semantic description
- preconditions
- topology fragment
- evidence
- compatible runtimes
- observed effect
- failure modes

Seed patterns from VentureLab:
- specify → decompose → dispatch
- persistent kanban
- independent review
- artifact hashing
- deterministic certification
- clean-copy patch validation
- evidence-required scoring

Patterns can be composed into new architecture candidates.
