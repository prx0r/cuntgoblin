# Agent Factory

The Agent Factory's product is an ArchitectureBuild.

## Inputs

- ArchitectureNeed
- existing systems/builds
- Pattern Registry
- HotSwap capability/economics
- benchmark suites
- cost budget

## Actions

1. reuse
2. compose patterns
3. fork existing
4. synthesize new topology
5. mutate candidate
6. benchmark
7. retain/reject
8. promote if evidence warrants

## Architecture synthesis

Candidate architecture includes:
- roles
- topology
- task decomposition
- state/memory
- tool scopes
- verifier
- recovery policy
- model slots
- HotSwap task policies
- runtime compiler target

## One-off candidate

A single novel solution may justify:

`EXPERIMENTAL_BUILD`

It does not justify a permanent architecture family.

This is essential.
