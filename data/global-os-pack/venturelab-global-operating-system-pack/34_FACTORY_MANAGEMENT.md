# Factory Management

Each Factory manifest declares:
- vision
- market scope
- accepted opportunity classes
- product archetypes
- Oracle dependencies
- WorkflowSpecs
- budget
- completion contracts
- outcome metrics

Manager tracks:
- queue depth
- active workers
- spend/reservations
- recent success
- blockers
- maintenance burden

Automatic pause conditions:
- integrity alert
- repeated zero-tolerance certificate failure
- spend anomaly
- source/legal concern
- severe provider instability
- schema incompatibility

Retirement preserves history/evidence.
