# Global Conventions Checklist

Every LLM task -> TaskSpec + HotSwap plan.
Every durable object -> stable ID + schema.
Every external input -> Artifact.
Every market/quality score -> method version + evidence.
Every public decision -> reason codes.
Every release -> certificate.
Every architecture -> ArchitectureBuild ID.
Every source poll -> source status separate from zero data.
Every process -> budget/time/concurrency bounds.
Every workflow -> idempotent trigger/job keys.
Every generated product -> generated MANIFEST.
Every epoch/public release -> Merkle checkpoint reference.
