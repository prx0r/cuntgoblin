# SEO / Web Publishing Standard

SEO pages are projections of structured evidence, not independently authored AI prose.

## Astro
Render essential content as HTML.
Hydrate only charts/comparison controls that need interaction.

## URL/canonical
- stable canonical URL
- self canonical
- 301 renamed/merged aliases
- avoid indexable query-parameter duplicates

## Sitemap
Split large indexes by entity class.
Respect search-engine sitemap file/URL limits.

## Required page elements
- unique useful title
- useful H1
- visible factual content
- as-of timestamp for changing data
- crawlable links
- canonical
- sitemap inclusion
- OpenGraph metadata
- accurate structured data where applicable

## Programmatic publishing gate
A page only exists if it contains enough unique structured evidence to answer a real
query. No mass near-duplicate pages.

## Performance
- static generation for high-volume public pages
- CDN caching
- hashed immutable assets
- lazy interactive islands
- optimized images
