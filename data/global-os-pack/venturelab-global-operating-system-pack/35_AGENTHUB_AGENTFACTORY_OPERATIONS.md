# AgentHub / Agent Factory Operations

## AgentHub
Weekly/on-demand ingest for selected repos/papers.
Benchmark jobs use a separate `ARCH_BENCH` queue/budget.

## Agent Factory
For one ArchitectureNeed:
- include simple baselines;
- synthesize 3–6 candidates;
- validate graph/security;
- simulate cheaply;
- real benchmark survivors;
- retain Pareto archive;
- stop on target, no improvement, invalidity or budget.

The winning experimental build may solve the original task immediately.
Promotion to a reusable named AgentSystem is a separate evidence decision.

Never spend unrestricted architecture-search budget while product verification is blocked.
