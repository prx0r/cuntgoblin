# Data Retention

Permanent where legally permitted/required for reproducibility:
- provenance-critical raw source artifacts
- canonical observations/events
- public release artifacts/certificates
- benchmark summaries
- Merkle checkpoints

Configurable retention:
- verbose LLM transcripts
- temporary clones
- build caches
- failed sandbox files

Prefer durable structured outcome/evidence objects over retaining huge prompts forever.

Never delete data needed to substantiate a current public claim.
