# Global Standards

Default:
- JSON Schema Draft 2020-12
- RFC 8785 JCS for canonical JSON
- SHA-256 content identity
- RFC3339 timestamps
- UUIDv7 with semantic prefixes
- SemVer
- OpenAPI 3.1-family REST description
- MCP stdio + Streamable HTTP
- A2A for interoperable complete-agent boundaries where useful
- OCI images/descriptors
- SPDX-compatible license expressions
- UTF-8
- standard HTTP caching semantics

AgentHub's architecture manifest should compose/reference established standards rather
than create yet another identity/tool protocol.
