## OpenRouter Datasets
- https://openrouter.ai/docs/api/api-reference/datasets/get-app-rankings
- https://openrouter.ai/docs/api/api-reference/datasets/get-rankings-daily

Key operational facts:
- public apps ranked by token usage
- popular/trending windows
- top-50 model daily token totals
- API key required
- tokenizers differ by upstream provider
- hidden/private apps excluded
- OpenRouter requires attribution when republishing dataset
