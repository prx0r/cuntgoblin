# Frontier Research Map

## Darwin Gödel Machine
Use:
- archive/tree of diverse self-improving agents
- empirical validation of modifications
- open-ended exploration

VentureLab transfer:
factory variants form a lineage tree; retain stepping stones instead of only current best.

Paper:
https://arxiv.org/abs/2505.22954

## Red Queen Gödel Machine
Use:
- evaluator/utility evolution across controlled epochs
- adversarial evaluator improvement

VentureLab transfer:
market/factory fitness definitions can evolve between epochs, but immutable
truth/safety gates remain fixed.

Paper:
https://arxiv.org/abs/2606.26294

## ShinkaEvolve
Use:
- population/archive
- island evolution
- parallel evaluation
- coding-agent skills/headless mutation workflows

VentureLab transfer:
bounded optimization backend for modules with explicit evaluator.

Repository:
https://github.com/SakanaAI/ShinkaEvolve

## AlphaEvolve
Use:
- LLM proposal ensemble
- automated evaluators
- program database
- evolutionary selection

VentureLab transfer:
cheap model explores broadly; stronger model deepens promising mutations;
evaluators decide.

Official:
https://deepmind.google/blog/alphaevolve-a-gemini-powered-coding-agent-for-designing-advanced-algorithms/

## Agentic Computation Graph survey
Use:
- template graph vs realized graph vs trace
- static vs dynamic workflows
- graph-level evaluation

Paper:
https://arxiv.org/abs/2603.22386

## Decision-aware Value of Information
Use:
- choose research that changes downstream decisions, not merely information gain.

Reference:
https://arxiv.org/abs/1703.08994
