# Outcome Oracle

Market intelligence becomes much more powerful when your own products become data sources.

## Outcomes

Software/API:
- API calls
- unique keys/users where available
- repeat use
- retention
- error rate
- GitHub clones/stars/forks/issues
- latency/uptime
- paid conversion/revenue

Content:
- search impressions
- clicks
- returning visitors
- newsletter subscribers
- API/RSS use
- content refresh rate

Dataset:
- downloads
- citations
- dependent projects
- repeat downloads

Benchmark:
- submissions
- external reproductions
- leaderboard usage

Agent system:
- installs
- successful runs
- resumed runs
- cost per success
- failure modes

## Outcome truth

Do not equate:
stars = users
or
page views = demand.

Keep metrics separate.

## Market feedback

A product's real outcomes update:
- buyer clarity
- WTP evidence
- distribution assumptions
- solution gap
- factory competence

This is how VentureLab becomes less speculative over time.
