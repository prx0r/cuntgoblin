# Solution Lab

The whole point is not to discover "ideas".
It is to discover PROBLEMS/OPPORTUNITIES and systematically generate possible solutions.

## Solution operators

For each Opportunity generate variants across mechanisms:

### Data
- data oracle
- monitoring feed
- benchmark
- dataset
- forecasting/decision API

### Automation
- workflow automation
- agent
- MCP tool
- integration/adapter
- CLI

### Market coordination
- discovery
- matching
- marketplace infrastructure
- procurement intelligence
- lead intelligence

### Decision support
- resolver
- optimizer
- calculator
- simulation
- comparison

### Publishing/education
- evidence-backed information site
- report/feed
- training/curriculum
- documentation

### Service
- concierge/manual-first service
- audit
- implementation service

## Product type is a decision

For each hypothesis calculate ProductArchetypeFit.

Example dimensions:

```text
requires_continuous_data
agent_is_primary_consumer
human_dashboard_required
needs_benchmarking
needs_two_sided_market
needs_package_distribution
needs_content_distribution
```

Then select compiler.

## Cheapest falsification before product

Every SolutionHypothesis produces an `ExperimentSpec`.

Examples:

Data/API:
- ingest 100 real useful records
- expose 3 endpoints
- ask external agent to complete 10 real tasks

Marketplace:
- manually test supply and demand separately before building platform

Content/intelligence:
- publish 10 evidence-backed pages and measure recurring use

Benchmark:
- prove task differentiates at least 2 systems

Agent system:
- prove architecture beats simple baseline on target task/cost

No Product promotion without explicit threshold.
