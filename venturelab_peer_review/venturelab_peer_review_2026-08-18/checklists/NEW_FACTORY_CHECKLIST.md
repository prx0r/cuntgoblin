# New Factory Gate

- [ ] At least three evidence-backed opportunities.
- [ ] Poor fit to an existing factory.
- [ ] Workflow is meaningfully repeatable.
- [ ] Shared-kernel reuse is high.
- [ ] Objective verification contract exists.
- [ ] Required data/connectors are available to the project.
- [ ] Publication is idempotent/controllable.
- [ ] Budget is boundable.
- [ ] Failure is containable/rollbackable.
- [ ] Downstream outcome is measurable.
- [ ] Plugin manifest can express it without kernel changes.
