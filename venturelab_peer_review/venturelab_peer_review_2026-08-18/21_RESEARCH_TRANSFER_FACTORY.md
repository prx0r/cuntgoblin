# Research-Transfer Factory

Goal: turn useful research into measured improvements while automatically rejecting hype.

```text
paper discovery
→ relevance screen
→ method extraction
→ reproduction-risk screen
→ minimal reproduction
→ baseline comparison
→ ablation/confidence
→ integrate only if win
```

States:
```text
REJECTED_NOT_RELEVANT
BLOCKED_NOT_REPRODUCIBLE
REPRODUCED_NO_GAIN
REPRODUCED_GAIN
INTEGRATED
```

Best first domains:
- routing,
- verified orchestration,
- agent eval,
- skills,
- retrieval/evidence.

A paper never ships because the abstract sounds good.
