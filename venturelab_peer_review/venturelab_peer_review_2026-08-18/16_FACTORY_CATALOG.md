# Factory Catalog

All factories share:

```text
DISCOVER → RESEARCH → PLAN → BUILD → VERIFY → PUBLISH → OBSERVE
```

## Tier A

1. **API / Data Oracle Factory**  
   Fragmented data → normalized source-backed API/MCP.

2. **Agent Factory**  
   Job → architecture → Hermes profile/skills/tools/models → eval → package.

3. **Connector Factory**  
   API/OpenAPI/docs → typed client + CLI + MCP + tests.

4. **Dataset / Benchmark Factory**  
   Sources → provenance/cleaning/splits/gold → harness/baselines.

## Tier B

10. **Data Pipeline Factory**

16. Template-to-Vertical Factory

## Genesis gate

Use the repo's existing `factory_genesis_decision()` as a first-class policy. A new factory requires multiple opportunities, poor fit to existing factories, repeatability, shared-infra reuse, adequate evidence and reuse ROI.
