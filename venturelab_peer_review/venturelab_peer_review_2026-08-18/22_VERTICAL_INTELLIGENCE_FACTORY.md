# Vertical Intelligence Factory

Create continuously refreshed, evidence-backed niche intelligence APIs/alerts.

```text
source registry
→ scheduled collectors
→ immutable observations
→ entity resolution
→ claim/event extraction
→ cross-source verification
→ freshness/expiry
→ API/MCP
→ alerts
```

Examples:
- model/provider pricing/availability,
- public software/security releases,
- public regulatory changes,
- scientific literature niches,
- public procurement,
- public statistical datasets.

Reuse the same evidence model as VentureLab itself.
