# Commerce / Shopify Factory

## Goal

Evidence-backed product opportunity → testable catalog/store artifact.

Not a mass-spam dropshipping generator.

## Pipeline

```text
signals
→ product candidates
→ demand/competition evidence
→ supplier/feed validation
→ unit economics
→ ranking
→ storefront plan
→ catalog/theme/pages
→ QA/compliance
→ explicit publish approval
→ outcome telemetry
```

## Product packet

- product/source,
- demand evidence,
- competitor/price evidence,
- estimated landed cost/margin,
- shipping/return constraints,
- differentiation,
- confidence,
- unknowns.

Use approved supplier feeds/APIs or user-provided data.

Do not generate fake reviews, false scarcity or unsupported product claims.

## Output

- product import data,
- theme sections/templates,
- page copy,
- metadata/SEO,
- analytics instrumentation,
- QA report.

## Verification

- required fields,
- links/assets,
- mobile smoke,
- price/economic policy,
- product-policy gate,
- evidence-backed claims,
- checkout remains merchant-controlled.

## Learning

Measure actual downstream signals such as clicks, carts, conversion and returns where available.
